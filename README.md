# 北京服装学院计算机知识学习社官方网站

> 北京服装学院计算机知识学习社官方在线网站项目

欢迎来到 **北京服装学院计算机知识学习社官方网站项目**！

本项目用于建设和维护计算机知识学习社的官方线上网站，为社团成员以及对计算机、人工智能等内容感兴趣的同学提供一个了解社团、获取信息和参与交流的平台。

---

## 📖 关于计算机知识学习社

**计算机知识学习社**（以下简称“计算机社”）是挂靠于**人工智能与创新设计学院**的学科竞赛、知识学习型社团。

社团成立于 **2020 年**，并于 **2023 年正式纳入校团委**。

计算机社不设置专业考核，也不要求成员必须具备计算机基础。

> **只要你想学习或者了解计算机、人工智能相关内容，都欢迎加入计算机知识学习社。**

目前社团主要围绕以下内容开展活动：

* 🏆 组织参加全国大学生计算机能力挑战赛等相关竞赛
* 🤖 人工智能、大模型等前沿技术学习
* 💻 Python、C++ 等计算机相关知识学习
* 🎓 计算机考研、保研等经验分享
* 🎤 计算机、人工智能相关讲座与竞赛分享
* 💬 社团成员日常交流与经验分享

---

## 🌐 关于本项目

这是计算机知识学习社的**官方在线网站项目**。

网站主要用于：

* 社团介绍
* 社团活动展示
* 社团公告与通知
* 学习资料整理
* 竞赛信息发布
* 计算机与人工智能相关内容分享
* 后续社团功能建设

随着社团的发展，网站也会持续进行更新和完善。

## 🚀 如何参与

如果你希望参与网站开发，可以按照以下基本流程：

```text

   ↓

   ↓

   ↓
等待 Review
   ↓
合并
```

具体的 Git、分支、Commit、Pull Request 等维护规范，请阅读：

**[项目贡献与维护说明 → CONTRIBUTING.md](CONTRIBUTING.md)**

## 📌 项目理念

我们希望这个网站能够随着计算机知识学习社的发展不断完善，也希望它不只是一个“展示社团”的网站。

它可以成为：

* 社员学习和实践的平台
* 社团活动的信息窗口
* 计算机与人工智能知识的分享平台
* 社团成员共同维护的开源项目

每一位参与维护的同学，都可以成为这个项目的一部分。
